# Security Policy

Security issues should not be disclosed publicly before a fix or mitigation is available.

Please report vulnerabilities through GitHub's private security reporting mechanism when enabled for the repository. If private reporting is unavailable, contact the project maintainers privately through the contact information published in the repository profile.

Do not include credentials, tokens, private keys, personal data, or production configuration in public issues.

Beluga Manager is designed to integrate with external platform APIs. Security reports involving authentication, authorization, credential handling, API integration, or cross-service data exposure are especially important.

See [SECURITY-ko.md](SECURITY-ko.md) for the Korean version.
